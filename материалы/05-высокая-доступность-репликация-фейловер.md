## Асинхронная репликация и доступность изменений на реплике

```bash
cd /opt/pg-course
docker compose -f compose.json exec -T -u postgres pg1 \
  patronictl -c /etc/course/patroni.json edit-config course \
  --set synchronous_mode=false --set synchronous_mode_strict=false --force
if [ "$(docker compose -f compose.json exec -T -u postgres pg1 \
  psql -X -At -d course -c 'SELECT pg_is_in_recovery();')" = t ]; then
  docker compose -f compose.json exec -T -u postgres pg1 \
    patronictl -c /etc/course/patroni.json switchover course \
    --leader pg2 --candidate pg1 --force
fi
docker compose -f compose.json exec -T -u postgres pg1 \
  patronictl -c /etc/course/patroni.json list
```

```sql
SELECT pg_is_in_recovery() AS in_recovery;
SET application_name = 'lecture05-A';
SET synchronous_commit = 'on';
SET statement_timeout = '15min';
CREATE TABLE IF NOT EXISTS lab.ha_events (
    event_key text PRIMARY KEY,
    description text NOT NULL
);
TRUNCATE lab.ha_events;
INSERT INTO lab.ha_events(event_key, description)
VALUES ('baseline', 'Исходная запись');
SELECT event_key, description FROM lab.ha_events ORDER BY event_key;
```

```sql
SELECT pg_is_in_recovery() AS in_recovery, event_key, description
FROM lab.ha_events ORDER BY event_key;
```

## Синхронное подтверждение и строгая политика сохранения

[документации режимов репликации Patroni](https://patroni.readthedocs.io/en/latest/replication_modes.html)

```bash
cd /opt/pg-course
docker compose -f compose.json exec -T -u postgres pg1 \
  patronictl -c /etc/course/patroni.json edit-config course \
  --set synchronous_mode=true --set synchronous_mode_strict=true \
  --set synchronous_node_count=1 --force
docker compose -f compose.json exec -T -u postgres pg1 \
  patronictl -c /etc/course/patroni.json list
```

[русской документации synchronous_commit](https://postgrespro.ru/docs/postgresql/18/runtime-config-wal#GUC-SYNCHRONOUS-COMMIT)

```sql
SHOW synchronous_commit;
SHOW synchronous_standby_names;
INSERT INTO lab.ha_events(event_key, description)
VALUES ('sync-flush', 'WAL устойчиво сохранён синхронной репликой')
ON CONFLICT (event_key) DO NOTHING
RETURNING event_key, description;
```

```sql
SELECT pg_get_wal_replay_pause_state() AS replay_state,
       event_key, description
FROM lab.ha_events ORDER BY event_key;
```

```sql
BEGIN;
SET LOCAL synchronous_commit = 'remote_apply';
INSERT INTO lab.ha_events(event_key, description)
VALUES ('sync-apply', 'Подтверждение ожидает применения на реплике')
ON CONFLICT (event_key) DO NOTHING;
COMMIT;
```

[русской документации мониторинга](https://postgrespro.ru/docs/postgresql/18/monitoring-stats)

```sql

FROM lab.ha_events WHERE event_key = 'sync-apply';
```

```sql

```

## Арбитражные узлы, кворум и защита единственного права записи

[документации конфигурации Patroni](https://patroni.readthedocs.io/en/latest/dynamic_configuration.html)

```bash
cd /opt/pg-course
docker compose -f compose.json exec -T -u postgres pg2 \
  patronictl -c /etc/course/patroni.json edit-config course \
  --set synchronous_mode=false --set synchronous_mode_strict=false \
  --set failsafe_mode=false --force
docker compose -f compose.json exec -T -u postgres pg2 \
  patronictl -c /etc/course/patroni.json show-config course
```

[официальной документации etcd](https://etcd.io/docs/v3.7/faq/)

```bash
cd /opt/pg-course
docker compose -f compose.json exec -T etcd1 \
  etcdctl --endpoints=http://etcd1:2379,http://etcd2:2379,http://etcd3:2379 \
  endpoint status --write-out=table
```

```bash
cd /opt/pg-course
docker compose -f compose.json stop -t 10 etcd3
docker compose -f compose.json exec -T etcd1 \
  etcdctl --endpoints=http://etcd1:2379,http://etcd2:2379 \
  --command-timeout=5s endpoint health
```

[документации Patroni](https://patroni.readthedocs.io/en/latest/dcs_failsafe_mode.html)

```bash
cd /opt/pg-course
docker compose -f compose.json stop -t 10 etcd2
primary_code=200
for attempt in $(seq 1 20); do
  primary_code=$(docker compose -f compose.json exec -T pg1 \
    curl --silent --max-time 2 --output /dev/null --write-out '%{http_code}' \
    http://pg2:8008/primary)
  printf 'HTTP /primary: %s\n' "$primary_code"
  if [ "$primary_code" = 503 ]; then break; fi
  sleep 3
done
test "$primary_code" = 503
```
