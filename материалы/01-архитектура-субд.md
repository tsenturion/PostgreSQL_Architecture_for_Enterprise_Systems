[обзоре управления базами PostgreSQL](https://postgrespro.ru/docs/postgresql/18/manage-ag-overview)

```sql
SELECT d.datname AS database_name,
       d.oid AS database_oid,
       n.nspname AS schema_name,
       c.relname AS table_name
FROM pg_database AS d
CROSS JOIN pg_namespace AS n
JOIN pg_class AS c ON c.relnamespace = n.oid
WHERE d.datname = current_database()
  AND n.nspname = 'sales'
  AND c.relkind = 'r'
ORDER BY c.relname;
```

## Процессы

```bash
cd /opt/pg-course
docker compose -f compose.json exec -T pg1 \
  ps -eo pid,ppid,user,rss,args --sort=ppid,pid
```

[документации представления `pg_stat_activity`](https://postgrespro.ru/docs/postgresql/18/monitoring-stats#MONITORING-PG-STAT-ACTIVITY-VIEW)

```sql
SELECT backend_type, count(*) AS process_count
FROM pg_stat_activity
GROUP BY backend_type
ORDER BY backend_type;
```

## Управление памятью

[документации `pg_shmem_allocations`](https://postgrespro.ru/docs/postgresql/18/view-pg-shmem-allocations)

```sql
SELECT name,
       pg_size_pretty(allocated_size) AS allocated
FROM pg_shmem_allocations
ORDER BY allocated_size DESC
LIMIT 8;
```

[документации `pg_backend_memory_contexts`](https://postgrespro.ru/docs/postgresql/18/view-pg-backend-memory-contexts)

```sql
SELECT name,
       level,
       pg_size_pretty(total_bytes) AS allocated,
       pg_size_pretty(used_bytes) AS used
FROM pg_backend_memory_contexts
ORDER BY total_bytes DESC
LIMIT 8;
```

[разделе PostgreSQL об использовании памяти](https://postgrespro.ru/docs/postgresql/18/runtime-config-resource#RUNTIME-CONFIG-RESOURCE-MEMORY)

```sql
SELECT name, setting, unit
FROM pg_settings
WHERE name IN (
    'shared_buffers',
    'work_mem',
    'hash_mem_multiplier',
    'maintenance_work_mem',
    'temp_buffers',
    'max_connections'
)
ORDER BY name;
```

[документации Docker о памяти](https://docs.docker.com/engine/containers/resource_constraints/#memory)

```bash
cd /opt/pg-course
docker inspect "$(docker compose -f compose.json ps -q pg1)" \
  --format 'memory_bytes={{.HostConfig.Memory}} shm_bytes={{.HostConfig.ShmSize}}'
```

## Файлы данных

[разделе об управлении объектами базы](https://postgrespro.ru/docs/postgresql/18/functions-admin#FUNCTIONS-ADMIN-DBOBJECT)

```sql
SELECT c.oid AS relation_oid,
       c.relname,
       pg_relation_filenode(c.oid) AS filenode,
       current_setting('data_directory') AS data_directory,
       pg_relation_filepath(c.oid) AS relative_path
FROM pg_class AS c
WHERE c.oid = 'sales.orders'::regclass;
```

```sql
SELECT '/opt/pg-course/data/pg1/18/docker/' ||
       regexp_replace(
           pg_relation_filepath('sales.orders'::regclass),
           '/[^/]+$',
           ''
       ) AS vm_directory,
       pg_relation_filenode('sales.orders'::regclass) AS filename_base;
```

[документации карты свободного места](https://postgrespro.ru/docs/postgresql/18/storage-fsm)

[документации карты видимости](https://postgrespro.ru/docs/postgresql/18/storage-vm)

[разделе PostgreSQL о формате страниц](https://postgrespro.ru/docs/postgresql/18/storage-page-layout)

```sql
SELECT order_id,
       ctid AS physical_position,
       current_setting('block_size')::integer AS page_bytes,
       status
FROM sales.orders
ORDER BY order_id
LIMIT 8;
```

[документации функций размера объектов](https://postgrespro.ru/docs/postgresql/18/functions-admin#FUNCTIONS-ADMIN-DBSIZE)

[разделе TOAST](https://postgrespro.ru/docs/postgresql/18/storage-toast)

```sql
SELECT pg_size_pretty(pg_relation_size(c.oid, 'main')) AS main_data,
       pg_size_pretty(pg_relation_size(c.oid, 'fsm')) AS free_space_map,
       pg_size_pretty(pg_relation_size(c.oid, 'vm')) AS visibility_map,
       pg_size_pretty(pg_table_size(c.oid)) AS table_storage,
       pg_size_pretty(pg_indexes_size(c.oid)) AS table_indexes,
       pg_size_pretty(pg_total_relation_size(c.oid)) AS total_storage,
       CASE WHEN c.reltoastrelid <> 0
            THEN c.reltoastrelid::regclass::text
       END AS toast_relation
FROM pg_class AS c
WHERE c.oid = 'sales.orders'::regclass;
```
