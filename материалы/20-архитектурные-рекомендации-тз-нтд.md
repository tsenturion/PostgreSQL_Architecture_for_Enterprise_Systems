## Методика приёмки и доказательства на стенде

```sql
SELECT statement_timestamp() AT TIME ZONE 'UTC' AS observed_at_utc,
       NOT pg_is_in_recovery() AS role_ok,
       current_setting('transaction_read_only') = 'off' AS write_mode_ok,
       COALESCE(
           (SELECT ssl FROM pg_stat_ssl WHERE pid = pg_backend_pid()), false
       ) AS tls_ok;
```

[Статистика PostgreSQL](https://postgrespro.ru/docs/postgresql/18/monitoring-stats)

```sql
SELECT statement_timestamp() AT TIME ZONE 'UTC' AS observed_at_utc,
       count(*) FILTER (WHERE state = 'streaming') AS streaming_receivers,
       max(pg_wal_lsn_diff(pg_current_wal_lsn(), replay_lsn))
           FILTER (WHERE state = 'streaming') AS max_replay_gap_bytes
FROM pg_stat_replication;
```
